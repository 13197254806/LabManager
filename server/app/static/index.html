服务器账号

登录密码

用于 ssh 用户名@服务器 密码登录，所有 GPU 服务器通用。平台只保存加密后的哈希。在服务器上用 passwd 改的密码会被平台覆盖，请在这里修改。

SSH 公钥 （可选，免输密码）

    如何生成 / 查看公钥？

    在你自己的电脑终端里执行（Windows 用 PowerShell）：

    ssh-keygen -t ed25519      # 一路回车即可，已有可跳过
cat ~/.ssh/id_ed25519.pub   # 复制输出的整行

    ⚠️ 只粘贴 .pub 结尾的公钥，私钥永远不要发给任何人。

    文件迁移

    从以前大家共用的账号（如 ubuntu）复制 .bashrc、git 配置、需要的 conda 环境，并把你自己的项目目录迁移到新账号的家目录，迁移后文件完全归你所有。迁移在服务器后台进行，可以关掉页面，进度随时回来看。
