    使用方式

    添加服务器

    内网地址要和 GPU 服务器在校园网里的 IP 一致，公网服务器靠它经 WebVPN 建立隧道。

    修改 Linux 用户名

    修改后约 1 分钟内在所有 GPU 服务器上生效：账号改名、家目录从 /home/旧名 移到 /home/新名（旧路径保留一个指向新家目录的快捷方式，写死旧路径的代码和 conda 环境仍可使用）。
    如果你在某台服务器上还有程序在运行，那台服务器会等程序全部结束后再改名，在此之前请继续用旧用户名登录。
